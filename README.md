# Hospital Patient Flow and Readmission Risk Analyzer

## Problem Statement
Hospitals often face challenges in managing patient flow and reducing readmission rates. High readmission rates can indicate inefficiencies in treatment, discharge planning, or follow-up care.

## Objective
To analyze hospital patient data to identify patterns in patient flow and determine key factors contributing to readmission risk.

## Dataset
This project uses a simulated dataset representing hospital patient records. The dataset includes:

- Patient ID  
- Age  
- Condition  
- Admission Type  
- Length of Stay  
- Readmission Status  
- Department  

## Methodology
- Data creation and preprocessing  
- Patient flow analysis across departments  
- Readmission pattern analysis  
- SQL-based querying for structured insights  
- Visualization of trends  

## Key Insights
- Chronic conditions such as diabetes show higher readmission rates  
- Emergency admissions have higher readmission probability  
- Longer hospital stays are associated with readmissions  
- Certain departments handle higher-risk patients  

## Recommendations
- Introduce follow-up programs for high-risk patients  
- Improve discharge planning for chronic cases  
- Implement readmission risk scoring systems  
- Optimize resource allocation across departments  

## Tools Used
- Python (Pandas, Matplotlib)  
- SQL (SQLite)  
- Google Colab  

## Project Structure
- `analysis.ipynb` – main notebook  
- `hospital_data.csv` – dataset  

## Outcome
This project demonstrates how data analysis and SQL can be used to derive insights and improve operational efficiency in healthcare systems.
